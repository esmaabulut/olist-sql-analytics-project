# Olist E-Commerce SQL Analytics Project

Bu proje, Brazilian E-Commerce (Olist) veri seti üzerinde SQL kullanılarak 
yapılmış bir veri analizi çalışmasıdır.

## Kullanılan Tablolar
- olist_orders_dataset
- olist_order_items_dataset
- olist_customers_dataset
- olist_products_dataset

## Klasör Yapısı
- `scripts/` → Analiz sorgularının bulunduğu SQL dosyaları
- `datasets/` → Kullanılan veri setinin Kaggle linki

## Analiz Adımları
1. Dimension Exploration – Kategorik değerlerin keşfi
2. Measures – Genel özet metrikler
3. Magnitude Analysis – Dimension bazlı kırılımlar
4. Ranking Analysis – En iyi / en kötü performans gösterenler
5. Change Over Time – Aylık trend analizi
6. Cumulative Analysis – Running total & moving average
7. Performance Analysis – Dönemsel karşılaştırma (MoM)
8. Customer Report (yakında eklenecek)
9. Product Report (yakında eklenecek)

## Kullanılan Araç
SQL Server (T-SQL)
